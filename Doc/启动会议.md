## 一、开场

**发言：**

> 我们是一群利用业余时间想做游戏的人。
>
> 业余做游戏最大的问题不是技术，是热情被时间消磨、项目越拖越散,所以目标是最快的速度做出一个完整的流程。
> 完整的能开始和结束的游戏。
>
> 所以我们定几条铁律：
> - **热情优先**。以推动进度为第一优先级，推动进度指有新功能的引入。这是为了保持大家的热情。
> - **不加班，不强制**。这不是工作，是爱好。
> - ###### **不许临时加需求**。需求只减不增，先跑起来再说。
>
> 我们最主要的目标是做一个**能跑起来的Demo**，不是做一个完美的游戏。
> 如果Demo好玩再决定做剩下来的事，不好玩就不做
> 
> 口号就八个字：**完成比完美重要，持续比冲刺重要。**

---

## 二、这是什么游戏

**发言：**

> 一句话概括：**这是一个让玩家在第一人称射击视角下，同时体验RTS指挥乐趣的游戏。**
>
> 你在战场上既是士兵也是指挥官：
> - 自己端枪射击
> - 同时框选部队、指挥它们移动和战斗
> - FPS和RTS两手都要抓
> - 当然我们会考虑如何在第一人视角下做好优化的体验。
>   比如：
>
> - 建造多个单位，单位越多，指挥官的护盾和能力越强，主打指挥官的操作，减少微操。
> - 强化部署静态炮台阵地，减少单位操作频率。

**顺便讲一下世界观（1分钟版）：**

> 故事发生在"卡俄斯星"——一颗有生命的流浪行星。
>
> 三大势力为争夺稀有矿物"源晶"来到这里，签署地面裁决协议，靠武力决定归属。
>
> 但有一个问题：这颗星球是活的。它有免疫系统。夜晚降临，星球会从地底唤醒"抗体生物"，无差别地攻击所有外来者。
>
> 所以你的敌人不只有别的玩家（PvP，以后做），还有这颗星球本身。先做PvE——抵御怪物。

## 三、核心循环（玩家每5分钟在做什么）

**发言：**

> Demo版本的核心循环就五个阶段，一轮大约7-10分钟：

| 阶段 | 时长 | 你在做什么 |
|------|------|-----------|
| 开局 | 30秒 | 着陆，拿枪，熟悉操作 |
| 白天 | 3分钟 | 探索、采集源晶矿、建采集器和兵营、生产兵力（建造炮台） |
| 黄昏 | 15秒 | 预警提示，回到基地附近 |
| 夜晚 | 2-3分钟 | 怪物波次来袭！FPS射击 + 同时框选指挥单位防守 |
| 战后 | 1-2分钟 | 天亮，修复建筑，补充兵力，准备下一波（更难） |

> Demo版只做**3个夜晚**，活下来就赢。

**图示：**

```
开局着陆 → [白天建造] → [黄昏预警] → [夜晚防守] → [战后恢复]
                ↑                                        ↓
                ←←←←←←← 每波难度递增 ←←←←←←←←←←←←←←←←←
```

## 四、最小Demo到底要做成什么样

**发言：**

> 第一版不做任何美术和音效。全程灰盒——方块、胶囊体、圆柱体。
>
> 唯一目的：**验证"FPS射击+RTS指挥"这个操作模式到底行不行。**

| 模块 | Demo范围 |
|------|----------|
| 场景 | 100m×100m灰盒地面，几个发光方块当矿 |
| 玩家 | 胶囊体 + 方块枪，WASD移动，左键射击 |
| 资源 | 只有一种——源晶 |
| 建筑 | 2种：采集器（建矿旁，自动产资源）、兵营（花钱造兵）->炮台 |
| 单位 | 1种：方块机器人，会自动打怪，可被框选指挥移动（先不做 |
| 敌人 | 1种：球形抗体生物，夜晚从地图边缘刷新 |
| 波次 | 第1波5只 → 第2波10只 → 第3波15只 |
| 操作 | 按住Alt呼出光标切RTS模式，松开回到FPS模式（先不做 |
| Win | 活过3波 |
| Loss | 人死了或建筑全没了 |

**明确不做（请大家记住，防止后续发散）：**

> - 不做PvP
> - 不做三方势力差异
> - 不做技能树/科技升级
> - 不做剧情/对话
> - 不做背包/装备系统
> - 不做多人联机
> - 不做音效、不做美术（灰盒到底）
> - 不做编队、不做小地图、不做存档读档

## 五、怎么协作

**发言：**

> 业余团队最怕"你等我、我等你"。所以我们这么干：

| 方面 | 方案 |
|------|------|
| 代码管理 | Git，`master`分支随时可跑，个人在`feature/xxx`上开发 |
| 任务看板 | 三列：待办 / 进行中 / 已完成 (飞书) |
| 任务粒度 | 每个任务 ≤ 2个小时的工作量，做完一个再接下一个 |
| 同步频率 | 每周不超过1次，每次不超过15分钟。只问三句：干了什么？遇到什么阻塞？下周干什么？ 核心：最大限度的减少会议。|
| 时间预算 | 每人每周至少1个晚上 × 每次0.5小时（不要求） |
| 做决定 | 每个模块指定一个人说了算，不投票、不扯皮 |
| 临时离开 | 公开说一声，写好交接文档，不催、不等 |
